Latest verification run: [GitHub Actions 39923425067](https://github.com/jhonny8765/agristore-pos/actions/runs/39923425067), implementation commit `b6f2d2f`, passed all application and database checks on October 23. The application checks include type checks, lint, 48 unit assertions, optimized build and eight practice-browser scenarios. The fresh Supabase stack applies all migrations, passes database lint and 98 pgTAP assertions, performs the restore drill, and runs three real database-connected browser scenarios. The drill uses the disposable container's local `supabase_admin` role to restore built-in Supabase functions; it does not use or request a production administrator credential.

The new owner scenario verifies inline refund/reason validation, PC retirement and re-registration without clearing transactions, opening-stock confirmation, stock refresh after an approved count, separate transfer dispatch/receipt, and sign-in to another business without exposing the previous catalog or transfer records.
